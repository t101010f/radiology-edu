# منصة الأشعة التثقيفية

مرجع عربي تفاعلي في تخصص الأشعة: تاريخها، أنواعها، والوقاية من الإشعاع وفق توصيات ICRP و IAEA و WHO.

تطبيق صفحة واحدة (SPA) بـ HTML و CSS و JavaScript فقط، بدون أي أدوات بناء أو مكتبات. التصميم على نمط تطبيقات iOS: ألوان النظام، قوائم مجمّعة، أشرطة زجاجية، ودعم كامل للوضع الداكن.

## التشغيل

- **أونلاين:** فعّل GitHub Pages من إعدادات المستودع (Settings ← Pages ← Branch: `main` / root).
- **محليًا:** افتح المجلد بأي خادم بسيط، مثل `python3 -m http.server`، ثم ادخل `http://localhost:8000`.

## هيكل المشروع

```
index.html            الهيكل الأساسي وشريط التنقل
css/style.css         التصميم (الوضع الفاتح والداكن)
js/app.js             الموجّه وعرض الصفحات والأدوات التفاعلية
js/icons.js           الأيقونات
js/i18n.js            نصوص الواجهة بالعربية والإنجليزية
js/data/en.js         الترجمة الإنجليزية لكل المحتوى (بنفس ترتيب الملفات العربية)
js/data/history.js    محطات تاريخ الأشعة + معلومات «هل تعلم؟»
js/data/modalities.js أنواع الأشعة التسعة
js/data/safety.js     الجرعات، الحدود، الخرافات، سلامة الرنين، الصبغات
js/data/glossary.js   قاموس المصطلحات
js/data/quiz.js       أسئلة الاختبار
assets/img/           الصور (مؤقتة حاليًا)
```

## اللغتان العربية والإنجليزية

زر **EN / ع** في الشريط العلوي يبدّل اللغة، ويتحوّل التخطيط تلقائيًا بين اليمين واليسار، وتُحفظ اللغة المختارة على الجهاز.

## إضافة محتوى

كل المحتوى في ملفات `js/data/`. لإضافة نوع أشعة أو مصطلح أو سؤال:
1. أضف العنصر في الملف العربي بنفس شكل العناصر الموجودة.
2. أضف ترجمته في `js/data/en.js` **بنفس الترتيب**، والنصوص فقط (الأرقام والمعرّفات تؤخذ من الملف العربي).
3. نصوص الواجهة (العناوين والأزرار) في `js/i18n.js` تحت `ar` و `en`.

## النماذج ثلاثية الأبعاد

صور الأجهزة ومحطات التاريخ وأدوات الوقاية نماذج ثلاثية الأبعاد مبنية بالكود في `js/scenes3d.js` بمكتبة three.js (موجودة داخل المشروع في `js/vendor/` برخصة MIT).

- **الصور:** تُولَّد إلى `assets/img/3d/*.jpg` بالأمر `python3 tools/render3d.py` (أو أسماء نماذج محددة بعده).
- **العارض التفاعلي:** زر «عرض ثلاثي الأبعاد» في صفحة كل نوع أشعة يفتح النموذج للتدوير والتقريب (`js/viewer3d.js`).
- **المخططات المقطوعة بتسميات:** مشاهد «كيف يعمل» والوقاية تُولَّد بنسختين `-ar.jpg` و `-en.jpg`، وتسمياتها مكتوبة داخل كل نموذج في `js/scenes3d.js` (الحقل `labels`) بخط تجوال من `tools/fonts/`.
- لتعديل شكل جهاز أو إضاءته أو تسمية، عدّل `js/scenes3d.js` ثم أعد توليد الصور.

## الرسوم التوضيحية

تُولَّد الرسوم من السكربت `tools/illustrations.py` بالعربية والإنجليزية (تشغيل: `python3 tools/illustrations.py assets/img ar` ثم `python3 tools/illustrations.py assets/img en`، والنسخ الإنجليزية تنتهي بـ `-en.svg`)، فأي تعديل على الألوان أو التسميات يتم من مكان واحد.

كل الصور في `assets/img/` رسوم SVG أصلية مرسومة للمنصة (بلا حقوق ملكية لطرف ثالث)، بأسلوب موحّد: خلفية داكنة تشبه صندوق عرض الأفلام، وخطوط فاتحة، وتسميات عربية.

- `h-*` تاريخ الأشعة
- `m-*` أنواع الأشعة (كل رسم يشرح طريقة عمل الجهاز)
- `s-*` الوقاية والسلامة
- `hero` صورة الرئيسية

لاستبدال أي رسم، ضع الملف الجديد بالاسم نفسه. وإذا كانت صيغته مختلفة، عدّل الامتداد في دالة `IMG` داخل `js/app.js`.

## تنبيه

المحتوى نسخة أولية للتثقيف، ويحتاج مراجعة أخصائي أشعة أو فيزيائي طبي قبل النشر العام.
